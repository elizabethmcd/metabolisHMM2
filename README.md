# metabolisHMM2

metabolisHMM2 is a tool to explore genome annotations and phylogenies using marker HMMs easily and reproducibly. The original [metabolisHMM python package](https://github.com/elizabethmcd/metabolisHMM) was introduced in the bioRxiv preprint ["metabolisHMM: Phylogenomic analysis for exploration of microbial phylogenies and metabolic pathways"](https://www.biorxiv.org/content/10.1101/2019.12.20.884627v2.full). metabolisHMM2 introduces a suite of improvements such as easier installation, cleaner code, and more.
